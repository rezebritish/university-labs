Лабораторная работа 3. Процедурное программирование. Передача массивов в подпрограммы. Рекурсии. Рекурсивные вызовы функций
Задания:
- Реализовать функцию, которая получает на вход массив и возвращает количество чётных чисел в нём.
- Написать рекурсивную функцию для вычисления факториала числа.
- Реализовать рекурсивную функцию для вычисления n-го числа Фибоначчи.



В этой работе реализован алгоритм сортировки на двух языках для сравнения:
* `cpp/` — реализация на C++ (производительная часть).
* `python/` — реализация на Python (быстрый прототип / протоколирование).
