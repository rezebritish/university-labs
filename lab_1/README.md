#Лабораторная работа 1. 
Форматированный ввод/вывод. Шаблоны
Задания:
- Написать программу, которая считывает с клавиатуры имя, возраст и средний балл студента, а затем выводит их в отформатированном виде (с выравниванием по столбцам).
- Составить программу для вывода таблицы значений функции y = sin(x) для x от 0 до 180 градусов с шагом 15°, отформатировав результат в виде таблицы.
- Реализовать шаблонную функцию maxElement, которая находит максимальный элемент в массиве любого типа (int, double, char).

В этой работе реализован алгоритм сортировки на двух языках для сравнения:
* `cpp/` — реализация на C++ (производительная часть).
* `python/` — реализация на Python (быстрый прототип / протоколирование).
