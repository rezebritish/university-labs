Лабораторная работа 2. Обработка одномерных массивов и двумерных массивов
Задания:
- Заполнить одномерный массив из N элементов случайными числами и найти среднее арифметическое положительных элементов.
- Найти минимальный элемент в двумерном массиве размером 5×5 и вывести его индексы.
- Написать программу, которая транспонирует квадратную матрицу (меняет строки и столбцы местами).


В этой работе реализован алгоритм сортировки на двух языках для сравнения:
* `cpp/` — реализация на C++ (производительная часть).
* `python/` — реализация на Python (быстрый прототип / протоколирование).
